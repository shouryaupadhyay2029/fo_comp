# Security Policy

## Supported Versions

The following versions of **VELOURA** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of VELOURA seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not create a public issue**: Please report vulnerabilities privately to avoid exposing user security.
2. **Email Notification**: Send an email detailing the security issue to `security@veloura.app`.
3. **Information to Include**:
   - Description of the vulnerability and potential impact.
   - Step-by-step instructions or proof-of-concept script to reproduce the vulnerability.
   - Any suggested mitigations or patches.

## Response Timeline

- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within 24 hours.
- **Assessment**: Our security team will assess the issue and confirm its impact within 48 hours.
- **Fix & Disclosure**: We will publish a patch release as soon as possible and coordinate public disclosure.

Thank you for helping keep VELOURA secure.
